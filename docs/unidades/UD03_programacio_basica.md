## 4. Desenvolupament de la unitat

### 4.1. Introducció

La programació és una eina fonamental per resoldre problemes de manera estructurada. En esta unitat aprendrem els conceptes bàsics que permeten crear programes senzills i funcionals.

### 4.2. Continguts explicats

#### Variables i tipus de dades

Una variable és un espai de memòria on guardem informació. Cada valor té un tipus: enter, decimal, text, etc.

#### Operadors

Operadors aritmètics (`+`, `-`, `*`, `/`) i lògics (`and`, `or`, `not`).

#### Condicionals

Permeten prendre decisions segons una condició.

#### Bucles

Permeten repetir instruccions fins que es complisca una condició o un nombre de vegades.

### 4.3. Exemples pràctics

```python
# Declaració de variables
nom = "Manuel"
edat = 16
print("Hola,", nom, "tens", edat, "anys.")
```

```python
# Condicional
nota = 7
if nota >= 5:
    print("Has aprovat")
else:
    print("Has suspés")
```

```python
# Bucle for
for i in range(1, 6):
    print("Iteració:", i)
```

```python
# Bucle while
contador = 0
while contador < 3:
    print("Comptador:", contador)
    contador += 1
```
