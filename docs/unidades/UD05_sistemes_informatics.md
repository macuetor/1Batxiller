## 4. Desenvolupament de la unitat

### 4.1. Introducció
Els sistemes informàtics són la base de qualsevol activitat digital. Conéixer els seus components i el funcionament del sistema operatiu permet utilitzar-los de manera eficient i segura. En esta unitat explorarem el hardware, el software bàsic i les tasques de manteniment.

### 4.2. Continguts explicats

#### Components del hardware
Descripció de CPU, memòria RAM, disc dur/SSD, targeta gràfica, placa base i perifèrics.

#### Sistemes operatius
Funcions principals: gestió de processos, memòria, fitxers, dispositius i interfície d’usuari.

#### Configuració bàsica
Ajustos de pantalla, so, xarxa, actualitzacions i permisos.

#### Manteniment
Actualitzacions, neteja de fitxers, control d’inici, antivirus i còpies de seguretat.
